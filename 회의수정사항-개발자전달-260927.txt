대성 매출프로그램 — 9/27 회의 수정사항 (개발 전달)
============================================================
· 화면 번호는 기존 전달문서(35화면) 기준
· 각 항목: [원문]=회의 발화 그대로 / [정리]=개발 지시 / [구분]=프론트/백엔드
· ★=이번 회의로 확정된 기존 미결항목  ⚠=착수 전 확정 필요(모호)  ⏳=발주처 자료 대기


[A] 먼저 읽어주세요 — 핵심 결정(구조·공통)
------------------------------------------------------------
A-1. 시스템 역할 확정 ★ (항목 4·5·6)
   - 매출프로그램 = 수불·자재 전부 관리(단독).  DSRE = 매출만 변경.
   - 특약점/자재 조회·처리도 DSRE 아니라 매출프로그램에서 직접.
   - 결과: 자재 단위 입고를 매출프로그램에서 직접 구현 / 도서 단위 수불 표시 빼고 자재별 입고.
   - → 기존 ★미결 3종(수불노출·자재입고·위탁창고) 이 방향으로 확정.
A-2. 다중선택 공통화 (3·12·21) — 지사 등 다중/세부 선택을 조회 화면 공통으로, 필요한 모든 화면 적용.
A-3. '사유' 입력 제거 공통 (9·12·20) — 폐기/통합매출(취소·삭제)/작업요청서에서 사유칸 제거.
A-4. 이메일 기능 누락 (13·17) — 통합매출조회·외상매출장조회 이메일 버튼 없음 → 추가(기존 매출프로그램에 있는 기능).
A-5. 특약점 PDF 연동 (18·19) — 매출에서 업로드 → 특약점 사이트 거래처별 노출. 양식 샘플 수령 후 착수.


[B] 이번 회의로 확정된 기존 미결(확인요청) 항목
------------------------------------------------------------
· 위탁출고 위치        → 매출등록에서 주문조회/등록으로 이동          (14)
· 자재 단위 입고 방식  → 매출프로그램에서 직접·자재별 입고            (4·5·6)
· 수불부/단가 노출     → 도서/수불 표시 빼고 자재 단위로              (6)
· 진행상태 단계        → DSRE와 동일 + 드롭다운으로 단계 조절         (20)
· 매출일괄등록 형태    → 기존 매출프로그램 화면 그대로                (15)

   [원문] 신규등록에서 담당자,주소,성적 처리. 필수 아니게 선택옵션으로. / (9/27) 성적은 신규주문등록 팝업의 담당자·주소·성적처리 부분. 여길 전부 선택옵션으로.

   [정리] 다중선택·세부선택 추가 + 공통화(필요 화면 전체 적용). → A-2

   [정리] ① 중복체크 추가  ② 특약점 DSRE 조회를 매출프로그램에서 직접(DSRE X). → A-1
   [구분] 백엔드(주)+프론트
