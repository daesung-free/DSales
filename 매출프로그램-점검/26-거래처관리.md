## ③ ⚠️ 민감정보 마스킹(`DB-73`) — 미구현이고 추적도 안 됩니다

요구 30p 기술검증란:
> 담보 컬럼 구성이 레거시 실측(`DB-27`)과 일치 확인.
> **사업자주민번호 등 민감정보 포함 — 암호화·마스킹 대상(`DB-73`)**

### 레거시

```vb
bossID as '사업자주민번호',        ' 거래처관리.vb:74 — 원문 그대로 출력
DataGridView_Edit.Columns("사업자주민번호").Width = 100
```
**마스킹 없이 그대로 표시**합니다.

### 웹

```ts
// features/customers/types.ts:94
{ key: 'ownerRegNo', label: '사업자주민번호', section: '사업자 정보', width: 130 }
```
**마스킹·암호화 로직 없음.** 일반 텍스트 컬럼입니다.

> 목업 데이터에 `사업자주민번호` 값이 **비어 있어** 화면상으로는 드러나지 않습니다.
> CLAUDE.md §4.6.9 의 *"개인정보(사업자번호·연락처·주소)는 넣지 않았습니다"* 방침 덕분입니다.
> **실서버 연결 시 그대로 노출됩니다.**

### 추적 상태 — 없습니다

`DB-73`·`마스킹`·`민감정보` 를 저장소 문서에서 grep 한 결과, 관련 항목이 **하나도 없습니다**
(`마일스톤-대조-260731.md:122` 의 「마스킹 덤프」는 **개발용 데이터 덤프** 얘기로 별개).

→ **요구사항이 지목한 `DB-73` 이 프론트 추적 목록에 없습니다.**

**이건 다른 미구현들과 성격이 다릅니다:**
- 반품입고·더프모 스키마 등은 **「향후 과제」로 문서에 남아** 있습니다
- `DB-73` 은 **아무 데도 없어** 연동 시 그냥 노출될 위험이 있습니다

### 권한 관점도 필요합니다

`viewer`·`sales` 역할도 `masters.view` 가 있어 **거래처관리를 볼 수 있습니다**(00번 확인).
사업자주민번호는 **역할 무관하게 전원에게 보이는** 상태가 됩니다.
