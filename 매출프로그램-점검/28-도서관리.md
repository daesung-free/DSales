### ★ 세트 상품일 때만 열립니다 — 실동작 검증

`BookScreen.tsx:30~45`:
```ts
const bomEnabled = isSetProduct(selected)
{ key: 'bom', label: '세트구성(BOM) 상세', disabled: !bomEnabled,
  disabledReason: selected
    ? `'${selected.bookName}' 은(는) 단품이라 세트 구성이 없습니다.`
    : '기본정보 탭에서 세트 상품을 선택하면 열립니다.' }

// 세트가 아닌 상품을 고르면 열려 있던 BOM 탭에서 빠져나옵니다.
const activeTab = tab === 'bom' && !bomEnabled ? 'info' : tab
```

**브라우저 실측**: 단품 행을 선택하면 탭이 `<button disabled aria-disabled="true">` 상태가 됩니다 ✅

CLAUDE.md §4.6.4 의 *"세트 상품일 때만 열립니다(`isSetProduct`)"* 가 지켜집니다.
**게다가 이미 BOM 탭을 보고 있다가 단품을 고르면 자동으로 기본정보 탭으로 빠져나옵니다** —
비활성 탭에 갇히지 않게 하는 처리입니다.
