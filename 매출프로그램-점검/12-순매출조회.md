## ③ 레거시 대비

### 순매출 산식 — 일치

레거시 `순매출조회.vb:497~498`:
```sql
순매출수량 = 매출수량 + 교사용수량_유가 + 반품수량
순매출금액 = 매출금액 + 교사용금액   + 반품금액
```

웹 목업(`datasets.ts:134~135`):
```ts
netQty: sales + paidQty + returns
netAmt: salesAmt + paidAmt + returnAmt
```
→ **동일**(`paidQty` = 유가 = 교사용 유가분). 05번 제품수불부의 순매출 산식과도 일관됩니다.

> ⚠️ 요구사항 16p 본문은 「매출 **−** 교사용 **−** 반품 = 순매출」로 적혀 있는데,
> 레거시·웹은 모두 **더하기**입니다. 반품이 음수 저장이고 교사용은 **유가분만** 더하는
> 구조라 결과는 같습니다. **요구사항 문구가 부호를 단순화해 적은 것**이며, 코드가 맞습니다.
