## ① ★ 레거시에 요구사항이 누락한 경고 체계가 있습니다

레거시 `외상매출현황조회.vb:1400~1430` — **두 컬럼에 3단계 경고**가 걸려 있습니다.

| 조건 | 표시 |
|---|---|
| ≥ 70% | 배경 **LightPink** |
| > 50% | 배경 **LightGreen** |

### 담보만기

| 조건 | 표시 |
|---|---|
| 만기까지 **< 90일** | 배경 **LightPink** |
| 만기까지 **< 180일** | 배경 **LightGreen** |
| **만기 경과(≤ 0일)** | 글자 **빨강** |

요구사항 25p 는 이 중 **마지막 하나만** 적었습니다:
> '담보보기' 체크 시 담보금액/만기일자/내용 등 여신담보 정보 노출
> (**만기경과 건 빨간색 표기** - 경고로직 확인 필요)

그리고 데이터 항목에도 **담보비율이 없습니다**:
> 거래처명, 사업자번호, 이월/매출/교사용/반품/입금/잔액/담보(금액,만기,내용)

**→ 요구사항이 레거시의 여신 리스크 지표를 통째로 빠뜨렸습니다.**

### `DB-27` 판정도 재검토가 필요합니다

요구사항:

## ③ ⚠️ 만기 경고가 3단계 → 1단계로 축소

웹 구현 (`closingScreens.ts:250~262`):
```ts
// 만기 경과 빨강 — 레거시 경고 계승. (config 는 .ts 라 JSX 대신 createElement)
render: (v) => {
  const expired = s < new Date().toISOString().slice(0, 10)
  return expired ? createElement('span', { className: 'text-danger' }, s) : s
}
```

**만기 경과(빨강)만 구현**돼 있고, 레거시의 **90일·180일 사전 경고 배경색은 없습니다.**

> 다만 **「만기 1개월 전 알림」은 대시보드에 별도 구현**돼 있습니다
> (`customers/rules.ts` + 백엔드 `CollateralExpiryBatch` 와 동일 판정).
> 재무팀 확정 요구(1개월 전)는 충족되지만, **레거시가 그리드에서 제공하던
> 90/180일 사전 신호는 이 화면에서 사라졌습니다.**

> S4 가 최초 FAIL 로 나온 것은 제 탐지 오류입니다. 클래스가 `.ag-cell` 이 아니라
> 내부 `<span class="text-danger">` 에 붙습니다. 게다가 목업 담보만기가
> `2026-05-31`(경과)·`2026-08-10`(당일)·이후 날짜들이라 렌더된 행에 경과 건이 없었습니다.

## ④ ★ 조회가 데이터를 씁니다 — 레거시 (BE-52 예외)

```vb
DB.RunQuery(sqlDeleteString)                          ' 1010행 — 먼저 전체 삭제
For Each row As DataRow In dt.Rows
    ' 이월등록일자 / 거래처코드 / 거래처명 / 이월Seq / 이월금액
    INSERT INTO carrData VALUES (...)                 ' 1016행 — 행마다 INSERT
    LogWrite(sqlInsertString)
Next
```

- **조회 화면인데 DML 을 수행**합니다. 24p(DML 0건)와 대비됩니다
- **`DELETE` 후 루프 `INSERT`, 트랜잭션 없음** — 08번 매출일괄등록과 같은
  `BE-24` 비원자적 패턴입니다. 중간 실패 시 이월 스냅샷이 **날아간 채 끝납니다**
- `LogWrite()` 가 여기서도 살아 있습니다 (01번 발견과 동일)

**웹은 이 부작용을 계승하지 않았습니다** — 순수 조회입니다. **올바른 판단**입니다.
이월 스냅샷 생성은 조회의 부수효과가 아니라 명시적 마감 처리여야 합니다.
