## ② 🔴 계층 집계가 3단계 → 2단계로 축소됐습니다

### 레거시 원문 (`매출액명세서.vb:106~108`)

```sql
case when grouping(left(catCode,1))=1 AND grouping(catCode)=1 AND grouping(bookCode)=1 THEN '총 계'
     when grouping(left(catCode,1))=0 AND grouping(catCode)=1 AND grouping(bookCode)=1 THEN '분류 계'
     when grouping(left(catCode,1))=0 AND grouping(catCode)=0 AND grouping(bookCode)=1 THEN '소 계'
```

**3단계 ROLLUP**입니다:

| 단계 | 기준 | 의미 |
|---|---|---|
| 소 계 | `catCode` | 분류 단위 |
| **분류 계** | **`left(catCode,1)`** | **상품군 단위** (H=교재, I=IC, S=기타고사 …) |
| 총 계 | 전체 | |

### 웹 실측

전체 조회(500건) 후 소계 라벨 집계:
```
{ "소계": 4, "합계": 1 }
```

→ **`분류 계`(상품군 단위) 중간 계층이 없습니다.** 2단계입니다.

### 왜 문제인가

- 요구사항 15p 가 **"계층적 집계(분류명→소계→**분류계**)"** 로 3단계를 명시합니다
- `left(catCode,1)` 상품군 구분은 05번 제품수불부에서도 확인된 **레거시의 핵심 분류 축**입니다
  (`DB-20`: "catCode 첫글자로만 구분")
- 상품군별 매출 소계를 못 보면 **교재/IC/기타고사 단위 실적 비교가 화면에서 불가능**합니다

**→ 수정 후보.** `shared/grid/subtotals.ts` 가 이미 그룹 소계를 지원하므로
   (`subtotals.test.ts` 로 고정돼 있음) 그룹 축을 하나 더 얹는 형태로 확장 가능해 보입니다.
