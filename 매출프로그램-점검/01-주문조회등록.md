## ② 레거시 대비

### 확인된 일치

**1. salesData INSERT = 25컬럼** — 문서 주장(`DB-31`)이 실제로 맞았습니다.

```vb
' UC_TabPages.vb:735
INSERT INTO salesData VALUES ('{0}' … '{24}')   ← 25개
  inputDate, TradeDate, TradeClass, curTradeType, 회차, CustCode, CustName, SchCode, SchName,
  분류코드, 분류명, 도서코드, 도서명, 0, 수량, 정가, 공급률, 금액, 구분, tMemo, "", "", "", 0, 0
```

끝의 5개(`"" "" "" 0 0`)는 **채워지지 않는 자리**입니다. 웹의 세액·총액은 여기 없습니다 —
레거시엔 세액 컬럼 자체가 없었고, 요구사항 6p에서 신규로 들어온 것입니다.

**2. 부호 규칙 — verbatim 확보**

```vb
' UC_TabPages.vb:694
'반품, 취소의 경우 -수량, -금액으로 변경
'폐기, 대체의 경우 -수량으로 변경
Select Case TradeType
    Case "반품", "취소"   : 수량 = -수량 ; 금액 = -금액
    Case "폐기", "대체"   : 수량 = -수량
End Select
```

웹 반품 등록 모달 안내문: **"등록 시 음수 매출로 차감됩니다"** → **일치**.

> 저장소 문서(`레거시-대비-구현현황.md`)는 "레거시가 **반품·폐기**를 음수로 저장"이라고
> 적었는데, 실제로는 **반품·취소·폐기·대체 4종**이고 **금액 음수화는 반품·취소만** 해당합니다.
> 결론(부호 주의)은 맞지만 기재가 부정확합니다.

**3. 위탁 개념 — 레거시 전무 확인**

레거시 전체 263개 파일에서 `위탁` grep 결과 **0건**. 요구사항정의서의
"위탁 미결·분할정산·초과정산방지 전량 부재" 주장이 확정됐습니다. 신규 개발이 맞습니다.

**4. 구분 → 회계구분 매핑 로직**

```vb
' UC_TabPages.vb:681
If TradeType = "출고" Then
    curTradeType = If(구분 = "매출", "매출", "무상")
Else
    curTradeType = TradeType

```
웹의 `SHIP_TYPE_TO_TRADE_KIND`(6종→3종 룩업)와 같은 취지. 레거시는 하드코딩 분기,
웹은 룩업 테이블로 구조화 — **의도적 개선**.

### ❓ 확인필요 — 무가 세분류 4종이 사라졌습니다

레거시 `Common.vb:27`의 구분(part) 콤보 값:

| 폼 | 구분 선택지 |
|---|---|
| `UC_TabPages`(교재) | 매출, **교사용, 학생용, 특강용, IC, 지사용** |
| `UC_TabPages_ETC`(기타고사) | 매출, 교사용, 반품, 취소 |
| `UC_TabPages_IC` | (공백), **지사용, 지자체용** |

웹의 출고유형 6종: 정상출고 / 위탁출고 / **증정용, 교사용** / 반품 / 취소

→ 레거시의 **학생용·특강용·IC·지사용·지자체용**이 웹에서는 **'증정용' 하나로 뭉쳐집니다.**
   등록 화면에서 이 값들을 입력할 방법이 없습니다.

**왜 문제일 수 있나:** 웹의 제품수불부 화면(`orderScreens.ts:62`)에는
`무가 = 교사용 + IC학생용 + IC + M+ + 기타` 분해 컬럼이 **숨김 상태로 존재**합니다.
즉 **집계 화면은 세분류를 보여줄 준비가 돼 있는데, 등록 화면에서 그 값을 만들 수 없습니다.**

- 요구사항정의서 6p가 출고유형 6종을 명시하므로 **스펙 준수는 맞습니다**
- 다만 레거시 데이터 마이그레이션 시 5종 → '증정용' 축약 매핑이 필요하고, 축약하면 되돌릴 수 없습니다
- 수불부 분해 컬럼이 신규 등록분에 대해 항상 0이 되는지 확인 필요

**→ 발주처·개발자 확인 대상.** 의도적 단순화인지, 아니면 세분류 입력 수단이 빠진 것인지.

## 부수 발견 (다른 작업에 쓸 것)

**1. 레거시에 `LogWrite()` 가 실제로 동작합니다**

```vb
DB.RunQuery(sqlString)
LogWrite(sqlString)        ← UC_TabPages.vb:759
```

CLAUDE.md는 "파일로그(LogWrite)도 대부분 주석처리"라고 적었는데, **출고 저장 경로에서는
살아 있습니다.** 실행된 SQL 전문을 파일로 남깁니다. 로그 설계 시 참고할 선례입니다.

**2. 메모에 `♬` 구분자**

```vb
tMemo = String.Concat(row.Cells("메모").Value, "♬", TextBox_Memo.Text)
' 원 주석: "메모를 쪼개기 위해... 괜히 이따우로 했네... 후~"
```
행 메모 + 전표 메모를 한 컬럼에 `♬`로 이어붙입니다. 웹 목업 시드에도 `'♬디랩 분당'` 형태로
남아 있어 **레거시 관행이 그대로 옮겨졌습니다.** 마이그레이션 시 분리 규칙 필요.

**3. `INSERT INTO ... VALUES` 에 컬럼명이 없습니다** — 전부 위치 기반. 컬럼 순서가 바뀌면
조용히 어긋납니다. `String.Format` 문자열 보간이라 SQL 인젝션도 그대로입니다.
